Usage

09

Link system.css in every HTML page and toggle themes with document.documentElement.setAttribute('data-theme', 'light').

<link rel="stylesheet" href="system.css">
<html data-theme="dark">

// Toggle
document.documentElement.setAttribute('data-theme', 'light');
